Bank Marketing Prediction
Binary Classification using Logistic Regression and Decision Tree
1. Project Overview
This project uses the Bank Marketing dataset from the UCI Machine Learning Repository to predict whether a customer will subscribe to a bank term deposit.

The main objective is to compare two supervised machine learning models: Logistic Regression and Decision Tree.

Research Question: Can we predict whether a bank customer will subscribe to a term deposit using customer information and previous marketing contacts?
2. Dataset
- Source: UCI Machine Learning Repository
- Observations: 4,521
- Target variable: y (Yes/No)
- Task: Binary Classification
3. Methodology
The project includes data exploration, preprocessing, model training and performance evaluation.
4. Model Evaluation
Both models are evaluated using Accuracy, Precision, Recall, F1-score, ROC-AUC and confusion matrices.
